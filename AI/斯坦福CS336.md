## 二、最推荐的同类书籍

### 1. 《Build a Large Language Model (From Scratch)》— Sebastian Raschka
这是目前**最贴近 CS336 理念**的实体书，和 CS336 一样强调**从零手写、不依赖高层封装**。

| 项目 | 内容 |
|------|------|
| **作者** | Sebastian Raschka（威斯康星大学麦迪逊分校教授） |
| **出版社** | Manning |
| **ISBN** | 9781633437166 |
| **GitHub** | https://github.com/rasbt/LLMs-from-scratch |
| **核心内容** | 从零实现 GPT 风格的 LLM：BPE 分词器、Transformer、预训练、SFT、RLHF |
| **特色** | 可在普通笔记本上运行；有完整单元测试；Bonus 材料极丰富（Llama 3、Qwen、Gemma 等从零实现） |

**Bonus 材料包括**：
- BPE 分词器从零实现
- KV Cache 实现
- Grouped-Query Attention、Multi-Head Latent Attention
- Mixture-of-Experts (MoE)
- Llama 3.2 / Qwen3 / Gemma 3 / Olmo 3 从零实现
- 性能优化技巧

## 三、其他高质量同类资源

### 2. Karpathy 的 "Neural Networks: Zero to Hero"
- **YouTube 免费系列**
- 从最基础的反向传播开始，一步步构建 GPT
- 风格非常"从零开始"，代码简洁
- 被多个推荐列表列为 LLM 入门首选 

### 3. 《Hands-On Large Language Models》— Jay Alammar, Maarten Grootendorst
- O'Reilly 出版
- 更偏**实践应用**，但可视化做得极好
- 适合理解 Transformer 内部机制 

### 4. 《NLP with Transformers》— Tunstall, von Werra, Wolf
- Hugging Face 团队出品
- 偏 Hugging Face 生态，但原理讲得很清楚 

### 5. 《Speech and Language Processing》(3rd ed. draft) — Jurafsky & Martin
- **免费 PDF**，持续更新到 2026 年
- 理论最全面，覆盖现代 NLP 和 LLM 的数学基础
- 适合作为 CS336 的"理论参考书" 

### 6. 《AI Engineering》— Chip Huyen
- O'Reilly 出版
- 偏**系统设计和工程部署**，和 CS336 的"系统"部分（Assignment 2）互补

## 四、学习路径建议

如果你想走 **CS336 风格（从零手写、深入原理）**：

```
第一阶段：基础
├── Karpathy "Zero to Hero"（视频）
├── 你提供的通识读本（中文，建立直觉）
└── Raschka《Build a Large Language Model (From Scratch)》Ch 1-5

第二阶段：系统与优化
├── CS336 Lecture 5-8 (GPU, Triton, 并行化)
├── CS336 Assignment 2（FlashAttention2, 分布式训练）
└── Raschka 书的 Bonus 材料（性能优化）

第三阶段：Scaling 与对齐
├── CS336 Lecture 9-17 (Scaling Law, 数据, 对齐)
├── CS336 Assignment 3-5
└── 《AI Engineering》（系统设计）
```
