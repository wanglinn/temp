## 生成代码示例

对于输入：
```sql
EXEC SQL EXECUTE
  BEGIN
    SELECT sal INTO :salary:ind FROM emp WHERE empno = :empno;
  END;
END-EXEC;
```

预处理器将生成：
```c
{ ECPGdo(__LINE__, 0, 0, NULL, 2, ECPGst_normal,
  "BEGIN\n  SELECT sal INTO :1 FROM emp WHERE empno = :2;\nEND;",
  ECPGt_int, &(salary), 1L, 1L, sizeof(int),
  ECPGt_int, &(ind), 1L, 1L, sizeof(int),
  ECPGt_EOIT,
  ECPGt_int, &(empno), 1L, 1L, sizeof(int),
  ECPGt_NO_INDICATOR, NULL, 0L, 0L, 0L,
  ECPGt_EORT);
}
```

（`argsresult` 为空，所以 `ECPGt_EOIT` 之后直接是 `ECPGt_EORT` 前的最后一个变量绑定。）
